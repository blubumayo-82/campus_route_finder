About Campus Route Finder

Campus Route Finder is a web application designed to help students, faculty, and visitors find the shortest walking route between any two buildings on campus using pure graph algorithms.

How Breadth-First Search (BFS) Finds the Shortest Route

  1. Queue Setup: We place the starting building into a First-In, First-Out (FIFO) queue and mark it as Level 0.
  2. Visit Neighbors Level by Level: We remove the next building from the front of the queue, examine all its connected walkway neighbors, and add any unvisited, open buildings to the back of the queue at the next level (Level + 1).
  3. Remember Parents: Whenever a new building is discovered, we record the building that discovered it in a parents dictionary. This leaves a trail of breadcrumbs pointing back to the start.
  4. Trace Back: As soon as the destination is reached, BFS stops searching. We follow the breadcrumbs backward from the destination to the start, and reverse the list to obtain the complete shortest route.

Why We Used an Adjacency List

We chose an adjacency list (a Python dictionary mapping each building to its list of neighboring buildings) because our campus network is sparse. With 20 buildings and only 29 walkways, most buildings only have 2 to 5 connections. An adjacency list uses minimal memory and allows BFS to inspect a building's immediate neighbors instantly without checking hundreds of empty grid cells.
